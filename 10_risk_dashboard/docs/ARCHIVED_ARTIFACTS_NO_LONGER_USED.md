# Archived: Artifacts No Longer Used

**Purpose:** List pipeline outputs and legacy artifacts that the dashboard **does not use**. We only save and serve artifacts tied to research questions (see [RESEARCH_QUESTIONS_ARTIFACTS.md](RESEARCH_QUESTIONS_ARTIFACTS.md)). These archived items may still be generated by older pipeline steps or retained for reference; do not add them to the dashboard API or frontend.

**Policy:** Only artifacts listed in RESEARCH_QUESTIONS_ARTIFACTS.md are produced and retained for production. Anything below is documented for history and cleanup.

---

## BupaR (process mining)

| Artifact | Reason not used |
|----------|------------------|
| `*_process_matrix.png` | Dashboard uses **Drug × Drug only** (`*_process_matrix_drug_drug.png`). Combined process matrix is not displayed. |
| `*_process_matrix_interactive.html` | Not used; frontend uses Drug × Drug PNG or JSON. |
| `*_frequency_map.png` | Optional process map; not tied to N2/N6. Not displayed on dashboard. |
| `*_trace_explorer.png` | Overall trace explorer (no pre/post). Dashboard uses pre-target only (`*_trace_explorer_pre_*`, trace_explorer_plot.json, trace_explorer_interactive.html). |
| `*_trace_explorer_post_*.png`, `*_trace_explorer_post_*_interactive.html` | Post-target trace explorer not shown in production drug-specific set. |
| `*_post_target_activity_frequency.png` | Frontend uses JSON for post-target bar chart; PNG not required. |
| Gantt charts (any) | Not produced for dashboard. See `9_dashboard_visuals/bupar/ARCHIVE_GANTT_REMOVAL.md` where referenced. |
| BupaR feature CSVs (`*_traces_*_bupar.csv`, `*_patient_features_bupar.csv`, etc.) | Patient-level outputs for follow-on work; not consumed by dashboard. Optional export to JSON remains for future use. |

---

## DTW (trajectories)

| Artifact | Reason not used |
|----------|------------------|
| Full DTW distance matrices / alignment CSVs (if kept beyond chart_data) | Dashboard uses `chart_data.json` and `sequence_heatmap.json` only. Heavy alignment outputs not served. |
| Non-drug sequence heatmap slices | Dashboard uses **drug-only** sequence heatmap; ICD/CPT slices not displayed. |
| Legacy trajectory CSVs not fed into chart_data | Only chart_data and sequence_heatmap (and overview/sample images) are used. |

---

## FP-Growth

| Artifact | Reason not used |
|----------|------------------|
| ICD or CPT itemset/network artifacts | Production is **drug names only** (N4). No item_type selector; ICD/CPT itemsets and networks are not displayed. |
| `*_icd_*_*.png`, `*_cpt_*_*.png`, `*_medical_*_*.html` | Same; drug-only visuals only. |
| Per–item-type network HTML (when different from combined_rules_network) | Dashboard uses `*_combined_rules_network.html` (drug association rules). |

---

## Feature Importance

| Artifact | Reason not used |
|----------|------------------|
| Per-model heatmaps (e.g. CatBoost-only, XGBoost-only) when aggregated is used | Dashboard shows one heatmap per cohort (or combined); aggregated FI only. |
| Per–age-band separate PNGs (if produced in addition to aggregated) | Single aggregated heatmap per cohort (or combined) is used. |

---

## Causal / SHAP+FFA

| Artifact | Reason not used |
|----------|------------------|
| Raw parquet only (no dashboard_data.json) | Dashboard consumes combined `dashboard_data.json` / `causal_data.json`; Lambda builds `chart_data` from that. |
| Unused interaction or importance files not in combine step | Only outputs that feed `combine_shap_ffa_results` and upload_causal_outputs_to_s3 are used. |

---

## General

- **Any visual or data file not listed in [RESEARCH_QUESTIONS_ARTIFACTS.md](RESEARCH_QUESTIONS_ARTIFACTS.md)** as “we keep and use” is out of scope for production. Pipeline owners can stop generating archived artifacts or move them to an archive bucket; the dashboard will not reference them.
- **Event-to-target BupaR visuals (all activity types):** If produced separately from drug-specific visuals, they are kept for research but are not controlled by the main BupaR dropdowns (see frontend copy). Their artifacts are still RQ-aligned (N2/N3) but documented as a separate “all activity types” set.
