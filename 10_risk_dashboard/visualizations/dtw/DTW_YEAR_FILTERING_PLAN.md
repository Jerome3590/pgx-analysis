# DTW Year Filtering Implementation Plan

**Archived.** Optional enhancement; not part of the final production workflow. DTW creation uses **`create_dtw_trajectories.py`** and **`create_dtw_visuals.py`**. See **`10_risk_dashboard/docs/README_visualization_plan.md`**. See `archived/dashboard_docs/README.md`.

---

## Current State
- DTW visualizations already use Plotly (cluster plots in 3D/1D)
- Data source: `dtw_features_{cohort}_{age_band}.csv` from `create_dtw_features.py`
- Visualizations generated by `create_dtw_plots.py`
- **Issue:** No year information in dtw_features CSV - only trajectory patterns and aggregated metrics

## Challenge
The DTW features CSV contains:
- `mi_person_key`: Patient ID
- `seq_pattern_str`: Sequence of events (no dates)
- `trajectory_length`: Number of events
- `dtw_min_distance`: Distance to cluster centroids
- `admin_icd_event_count`: Count of admin events
- **Missing:** Year of events/target date

## Solution Approach

### Option 1: Add Year to DTW Features (RECOMMENDED)
Modify `create_dtw_features.py` to include year information:
1. Extract year from target event date (for target patients)
2. Extract year from last event date (for control patients)
3. Add `event_year` column to dtw_features CSV
4. Modify `create_dtw_plots.py` to filter by year and create interactive dropdowns

### Option 2: Extract Year from Model Data at Visualization Time
- Load model_data during visualization creation
- Join with dtw_features on mi_person_key
- Extract year from target-aligned events
- More complex, requires additional data loading

## Implementation Steps (Option 1)

### Step 1: Modify `create_dtw_features.py` (Lines ~670-750)
Add year extraction to the feature aggregation:
```python
# After collecting trajectories, before writing features
if 'target_event_date' in cohort_df.columns:
    # For target patients: use target event year
    cohort_df['event_year'] = pd.to_datetime(cohort_df['target_event_date']).dt.year
else:
    # For control patients: use last event year from trajectory
    # Extract from seq_pattern_str or use default 2017 (midpoint of 2016-2018)
    cohort_df['event_year'] = 2017

# Include event_year in dtw_features output
features_df = features_df.merge(
    cohort_df[['mi_person_key', 'event_year']], 
    on='mi_person_key', 
    how='left'
)
```

### Step 2: Modify `create_dtw_plots.py` (Lines ~96-278)
Update `create_trajectory_cluster_plots()` to generate year-filtered interactive HTML:

**Changes:**
1. Group data by `event_year` (2016, 2017, 2018)
2. Create "All Years" aggregation
3. Build Plotly figure with multiple traces (one per year)
4. Add `updatemenus` dropdown for year selection
5. Similar to BupaR implementation

**Code pattern:**
```python

                x=x[mask], y=y[mask], z=z[mask],
```

- **Data Volume:** DTW features typically 1000-5000 patients per cohort/age_band
- **Performance:** Adding year filtering adds minimal overhead (simple pandas groupby)
- **Storage:** Each interactive HTML ~500KB (vs ~2MB PNG)
- **Backwards Compatibility:** Keep PNG URLs for fallback
