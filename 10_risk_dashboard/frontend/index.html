How to use the PGx Risk Assessment Dashboard. All content stays on this page.

Overview

This dashboard supports F1120 Opioid ED Visit risk and Polypharmacy risk. Each cohort supports age bands 13–114 (13-24, 25-44, 45-54, 55-64, 65-74, 75-84, 85-114). Use the Opioid ED or Polypharmacy tab to switch cohort; age selects the age band within that cohort.

Tabs

Cohort: Opioid ED | Polypharmacy (use these to switch cohort and load the right metadata). Both cohorts support age bands 13–114.

Main tabs: Risk Assessment | Drugs | ICD Codes | CPT Codes | Causal Analysis | DTW Trajectories | FP-Growth Patterns | BupaR Process Mining | PGx Cohort | Feature Importance | PGx Patient Card | Documentation

  • Risk Assessment — Enter age, select codes (via Drugs / ICD / CPT tabs), then click Calculate Risk Score. Use Edit codes to change selections.
  • Drugs — Search and add drugs for your patient. Selections are used for the risk calculation. A visual display shows all selected drugs with option to remove them.
  • ICD Codes — Search and add ICD codes for your patient. Used for risk in the Opioid ED cohort only. Selections are used for the risk calculation.
  • CPT Codes — Search and add CPT codes for your patient. Used for risk in the Opioid ED cohort only. Selections are used for the risk calculation.
  • Causal Analysis — View causal importance and interaction plots by cohort and age band.
  • DTW Trajectories — Dynamic time warping trajectory visualizations.
  • FP-Growth Patterns — Frequent itemset and network visualizations.
  • BupaR Process Mining — Process mining and activity frequency charts.
  • Feature Importance — Aggregated feature importance heatmaps by cohort (from Step 3a / 2_feature_importance).
  • PGx Patient Card — Generate a PGx card from SNP/phenotype input.

Research questions and visualizations

Each research question is answered by one or more dashboard tabs and their visuals.

Original research questions

  • RQ1 (Polypharmacy) — Does drug window influence target outcome? Which drugs are involved? Is there a temporal/ordering aspect? → Risk Assessment, Causal Analysis (risk score, FFA + SHAP), FP-Growth (drug itemsets, network), BupaR (sequences to target, Gantt).
  • RQ2 (Opioid ED) — What CPT/ICD codes and drugs predict OPIOID_ED? Predictive sequences? Feature importance? High-risk trajectories? Formal causality? → FP-Growth + Causal Analysis (itemsets, network, FFA, SHAP), BupaR (top sequences, pre-target frequency), DTW Trajectories (trajectory overview, high-risk vs low-risk), Causal Analysis (FFA, interactions).

Workflow

  1. Set Age on Risk Assessment (this loads metadata and determines age band; age 13–114 supported for both cohorts).
  2. Open Drugs tab, search and add the drugs you need. View selected drugs in the display area.
  3. For the Opioid ED cohort, also open ICD Codes and CPT Codes tabs to add additional codes.
  4. Return to Risk Assessment and click Calculate Risk Score.
  5. Use Compare Scenarios to compare different code sets.
  6. Explore visualizations on other tabs (Causal Analysis, DTW, etc.) to understand feature importance and patterns.

Feature importance sources for visuals

BupaR, DTW, and FP-Growth use different feature-importance inputs:

  • BupaR Process Mining and DTW Trajectories use SHAP/FFA combined — allowed codes (drug, ICD, CPT) come from merged SHAP and FFA causal importance (Steps 7 and 8). The pipeline writes these to a single allowed-codes file per cohort/age band; R (BupaR) and Python (DTW) use that list only.
  • FP-Growth Patterns use final feature importances — allowed items come from the cohort feature importance list (Step 3b, refined/leakage-filtered). FP-Growth does not use the SHAP/FFA combined list.

So: BupaR and DTW visuals are driven by SHAP/FFA combined; FP-Growth visuals are driven by the final (cohort) feature importance list.

Technical notes

The backend uses an ensemble of CatBoost, XGBoost, and XGBoost RF models. Metadata (drugs, ICD, CPT) is filtered by cohort and age band. All tabs use the same page; nothing here navigates you away to a separate doc page.

Note for Polypharmacy cohort: Only drugs are used for risk calculation. ICD and CPT code tabs are hidden for this cohort. Both cohorts support age bands 13–114.
