## Journal Requirements

### CTS — Clinical and Translational Science
**ISSN:** 1752-8062 | **Editor:** John A. Wagner, MD, PhD | **Email:** cts@ascpt.org  
**Submit:** https://cts.msubmit.net/cgi-bin/main.plex  
**APC:** Wiley Open Access (fee varies; check current schedule)

| Type | Word Limit† | Abstract | Refs | Figs+Tables |
|---|---|---|---|---|
| **Article** | 4,000 | 250, structured | 50 | 7 |
| **Review / Systematic Review** | 8,000 | 250, structured | 100 | 8 |

†Excludes title page, abstract, references, acknowledgements, tables, figures.

**Required sections (Article):** Title Page → Abstract → Study Highlights → Introduction → Methods (IRB) → Results → Discussion → Acknowledgements → Author Contributions → References → Figure Legends → Tables

**Study Highlights (CTS):**
- Required for all original research (incl. Brief Reports, Systematic Reviews)
- ≤ **280 words** for all four answers combined
- 4 questions:
  1. What is the current knowledge on the topic?
  2. What question did this study address?
  3. What does this study add to our knowledge?
  4. **How might this change clinical pharmacology or translational science?**

**Author Contributions — STRICT FORMAT (CTS):**  
Only these 4 roles are allowed (+ optional 5th):
> *A.B.C. wrote the manuscript; A.B.C. designed the research; A.B.C. and D.E. performed the research; A.B.C. analyzed the data; A.B.C. contributed new reagents/analytical tools.*

**Other key requirements:**
- Abstract: structured, no headers, no references
- IRB approval statement required in Methods (protocol name, number, date)
- Funding and COI on title page
- Data availability statement + code repository link
- AI use disclosure in Acknowledgements or Methods if used
- References: ≤6 authors, first 3 + *et al.* (>6)
- Supplementary: ≤8 files, ≤10 MB each; combine into one PDF when possible

### PSP — CPT: Pharmacometrics & Systems Pharmacology
**ISSN:** 2163-8306 | **Editor:** France Mentré, MD, PhD | **Email:** psp@ascpt.org  
**Submit:** https://psp.msubmit.net/cgi-bin/main.plex  
**APC:** $3,610 (ASCPT member) / $4,350 (non-member) — **full OA, required upon acceptance**

| Type | Word Limit† | Abstract | Refs | Figs+Tables |
|---|---|---|---|---|
| **Article** | 4,000 | 250, structured | 50 | 7 |
| **Review / Tutorial** | 8,000 | 250, structured | 100 | 8 |

†Excludes title page, abstract, references, acknowledgements, tables, figures.

**Required sections:** Title Page → Abstract → Introduction → Methods (IRB) → Results → Discussion → **Study Highlights** → Acknowledgements → Author Contributions → References → Figure Legends → Supplementary Titles

**Study Highlights (PSP):**
- Required after Discussion
- ≤ **150 words** for all four answers combined (stricter than CTS/CPT)
- 4 questions:
  1. What is the current knowledge on the topic?
  2. What question did this study address?
  3. What does this study add to our knowledge?
  4. **How might this change drug discovery, development, and/or therapeutics?**

**Author Contributions (PSP):**  
Standard roles (flexible CRediT format accepted):
> Wrote Manuscript, Designed Research, Performed Research, Analyzed Data, Contributed New Reagents/Analytical Tools

**Other key requirements:**
- **Data/Model Code:** Must provide example code + datasets in Supplementary or public repo
- Data accessibility statement with repo link required
- IRB approval in Methods
- Funding and COI on title page
- AI use disclosure in Acknowledgements or Methods
- References: ≤6 authors, first 3 + *et al.* (>6)
- Supplementary: ≤8 files; recommend combining into one PDF

### CPT — Clinical Pharmacology & Therapeutics
**ISSN:** 1532-6535 | **Editor:** Karen Rowland Yeo, PhD | **Email:** cpt@ascpt.org  
**Submit:** https://cpt.msubmit.net/cgi-bin/main.plex  
**APC:** Optional Open Access (fee varies); not mandatory OA

| Type | Word Limit† | Abstract | Refs | Figs+Tables |
|---|---|---|---|---|
| **Article** | 4,000 | 250, **unstructured** | 50 | 7 |
| **Review / Tutorial** | 8,000 | 250, **unstructured** | 100 | 8 |

†Text only; excludes title, references, tables, figures.

**Required sections (Article):** Introduction → Materials and Methods (IRB) → Results → Discussion → **Study Highlights** → Acknowledgements → Author Contributions → References → Tables → Figure Legends

**Study Highlights (CPT):**
- Required for all original research (incl. Brief Reports, Systematic Reviews)
- ≤ **250 words** for all four answers combined
- 4 questions:
  1. What is the current knowledge on the topic?
  2. What question did this study address?
  3. What does this study add to our knowledge?
  4. **How might this change clinical pharmacology or translational science?**

**Author Contributions — STRICT FORMAT (CPT):**  
Only these 4 roles allowed (+ optional 5th):
> *A.B.C., D.E., and X.Y.Z. wrote the manuscript; A.B.C. designed the research; A.B.C. and D.E. performed the research; A.B.C. analyzed the data; A.B.C. and X.Y.Z. contributed new reagents/analytical tools.*

**COI wording:** "The authors declared no competing interests for this work."  
**Funding wording (if none):** "No funding was received for this work."

**Other key requirements:**
- Abstract: **unstructured**, no headers, no abbreviations, no references
- IRB approval in Methods
- Drug names: generic only (brand in parentheses on first use)
- HUGO gene symbols in parentheses on first mention
- References: ≤6 authors (first author + *et al.* if >6 — stricter than CTS/PSP)
- Supplementary: ≤8 files, ≤10 MB each
- CONSORT checklist required for RCTs

## Critical Differences Across Journals

| Requirement | PSP | CTS | CPT |
|---|---|---|---|
| Abstract format | **Structured** (Bg/Meth/Res/Conc) | **Structured** (no headers) | **Unstructured** |
| Study Highlights word limit | **≤ 150 words** | **≤ 280 words** | **≤ 250 words** |
| Study Highlights Q4 | "…drug discovery, development, and/or therapeutics?" | "…clinical pharmacology or translational science?" | "…clinical pharmacology or translational science?" |
| Author Contributions format | Flexible CRediT | **Strict 4 roles only** | **Strict 4 roles only** |
| OA requirement | **Mandatory** (APC required) | Wiley OA available | Optional OA |
| Reference style | ≤6 authors, first 3 + et al. | ≤6 authors, first 3 + et al. | first author + et al. if >6 |

## Author Contributions Templates

### CTS / CPT strict format
```
R.J.D. wrote the manuscript; R.J.D. and E.T.P. designed the research;
R.J.D. performed the research; R.J.D. analyzed the data;
R.J.D. contributed new reagents/analytical tools.
```

### PSP standard format (CH2, CH4)
```
Conceptualization, R.J.D. and E.T.P.; methodology, R.J.D.; software, R.J.D.;
formal analysis, R.J.D.; writing—original draft, R.J.D.;
writing—review and editing, R.J.D. and E.T.P.;
supervision and domain expertise (clinical pharmacology and pharmacogenomics), E.T.P.
All authors have read and agreed to the published version of the manuscript.
```
