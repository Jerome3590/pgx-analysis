# Manuscript Submission Build Guide

## Overview

Each chapter is authored in a single Quarto Markdown file (`.qmd`) and built
into submission-ready files via `build.ps1`. The DOCX output is the primary
submission artifact; supplementary figures (PNG) and supplementary tables
(DOCX) are generated as separate files, exactly as journals require.

---

## Quick Reference

| Command | Output | Use |
|---|---|---|
| `.\build.ps1 -Submit -Chapter N` | `output/submission/<journal>/chNN/` | **Full submission package (DOCX + TIFFs)** |
| `.\build.ps1 -Submit` | All chapters | Full batch submission build |
| `.\build.ps1 -Docx -Chapter N` | `output/edits/<journal>/chNN_draft.docx` | Advisor review draft only |
| `.\build.ps1 -Chapter N` | `output/<journal>/chNN.pdf` | PDF proof |
| `.\build.ps1 -Full` | `output/dissertation_dixon_<stamp>.pdf` | Full dissertation PDF |

## DOCX Build Pipeline (4 Passes)

Running `.\build.ps1 -Docx -Chapter N` executes the following passes in order:

### Pass 1 — Quarto Render (image placeholders)
```
quarto render chNN.qmd --to docx --lua-filter templates/suppress_images.lua
```
- Quarto converts the `.qmd` to a raw DOCX using `templates/reference.docx` as
  the style template.
- The Lua filter **replaces every figure with a plain-text placeholder** of the
  form `[IMAGE: filename.png]`. This avoids Quarto embedding low-resolution or
  incorrectly sized images.
- All markdown prose, tables, citations, and cross-references are rendered
  normally at this stage.

### Pass 2 — Image Handling (journal-specific)

**PSP chapters (CH_2, CH_4) — `format_psp_manuscript.py`**
```
python templates/format_psp_manuscript.py output/edits/cpt_psp/chNN_draft.docx \
    --chapter N
```
PSP requires figures to be submitted as **separate TIFF files**, not embedded.
- Replaces every `[IMAGE: path]` placeholder with an italic callout:
  `[Figure N near here]`
- Detects the caption paragraph (pandoc places it as the next `w:p` sibling in
  the same `w:tc` table cell that wraps each figure)
- Removes captions from their inline positions and appends them as a
  **Figure Legends** section at the end of the document (after References),
  per PSP style requirements
- No images are embedded — figures are uploaded as separate TIFF files
  (see `export_figures_psp.py` / `.\build.ps1 -ExportFigures`)

**All other journals (CTS, CPT, dissertation) — `insert_docx_images.py`**
```
python templates/insert_docx_images.py output/edits/<journal>/chNN_draft.docx \
    --chapter-dir CH_N/
```
- Scans the DOCX for `[IMAGE: filename]` placeholder paragraphs.
- Reads the source PNG file from the chapter's `figures/` directory.
- Inserts each image as an **anchored float** at the correct size (inches),
  replacing the placeholder paragraph.
- Images are embedded for reviewer convenience.

### Pass 2b — Table & Field Fixes (`fix_docx.py`)
```
python templates/fix_docx.py output/edits/<journal>/chNN_draft.docx
```
- Left-justifies all table cell text (overrides pandoc's default centering).
- Marks all TOC field codes dirty so Word recalculates page numbers on first
  open.

### Pass 2c — Title Page Placement (`move_titlepage.py`)
```
python templates/move_titlepage.py output/edits/<journal>/chNN_draft.docx
```
- Locates the `**TITLE PAGE**` content block in the body (rendered from the
  `.content-visible when-format="docx"` div in the QMD).
- Moves the block to appear **after the YAML-generated title and authors but
  before the abstract**, so the final page 1 structure is:

  ```
  [Manuscript title heading]   ← YAML title, large font, top of page 1
  [Author names]               ← YAML authors
  TITLE PAGE
  Affiliations: …
  Corresponding Author: …
  Author Contributions: …
  Funding: …
  Conflicts of Interest: …
  Ethics Statement: …
  ────────────────── page break ──────────────────
  [Abstract]                   ← page 2
  [Table of Contents]
  [Body text]
  ```

- Inserts a hard page break after the last title page element.

### Pass 2d — Supplementary Tables (`make_supp_tables.py`)
```
python templates/make_supp_tables.py --chapter N
```
- Generates standalone DOCX files for each supplementary table defined for
  that chapter.
- Output goes to `output/<journal>/supplementary/chNN/Table_SX.docx`.
- For tables generated by the analysis pipeline (e.g., 115 DDI pairs), a
  `Table_S1_NOTE.txt` placeholder is written as a reminder.

## How the Title Page Works in the QMD

Each QMD contains a Quarto conditional content block that renders **only when
building to DOCX** (invisible in PDF output):

```markdown
::: {.content-visible when-format="docx"}
**TITLE PAGE**

**Affiliations:**

^1^ Department of Pharmacotherapy and Outcomes Science …
^2^ Ph.D. Program in Integrative Life Sciences …
^3^ ConvergenceLabs@VCU—Health Outcomes …

**Corresponding Author:** R. Jerome Dixon · dixonrj@vcu.edu · ORCID: …

**Author Contributions:** R.J.D. and E.T.P. wrote the manuscript; …

**Funding:** This research received no external funding.

**Conflicts of Interest:** The authors declare no conflicts of interest.

**Ethics Statement:** IRB waiver HM20022300 …

:::
```

- The `**TITLE PAGE**` text acts as the **start marker** for `move_titlepage.py`.
- The block ends at the first Heading 1 paragraph (Introduction / Background /
  Methods), which acts as the **end marker**.
- `move_titlepage.py` moves the block between the YAML-rendered authors and the
  abstract at build time — no manual editing of the DOCX is needed.

## Output File Reference

Every artifact produced by the build pipeline, its save location, and how the
file name maps to in-text references.

### Canonical Naming Rules

| Artifact | Pattern | Example | In-text label |
|---|---|---|---|
| Main manuscript | `chNN_<journal>_draft.docx` | `ch02_psp_draft.docx` | — |
| Main figure (TIFF) | `Figure_N.tiff` | `Figure_1.tiff` | `[Figure 1 near here]` (PSP) |
| Supplementary figure (PNG) | `Figure_SN.png` | `Figure_S1.png` | `Supplementary Figure S1` |
| Supplementary figure (TIFF) | `Figure_SN.tiff` | `Figure_S1.tiff` | `Supplementary Figure S1` |
| Supplementary table | `Table_SN.docx` | `Table_S2.docx` | `Table S2` |

**Rules:**
- N is the consecutive citation order (1, 2, 3 …), not the QMD figure label
- Supplementary items use `S` prefix: `Figure_S1`, `Table_S2`
- Underscores, not spaces or hyphens, in all filenames
- No journal prefix in filename — folder path carries the journal context

## PSP-Specific Submission Requirements

### Figures

| Attribute | Requirement |
|---|---|
| **Format** | TIFF (preferred), PDF, or EPS |
| **Color mode** | CMYK for color images |
| **Halftone / color** | 300 dpi |
| **Images containing text** | 400 dpi |
| **Line art** | 1,000 dpi |
| **Single-column width** | 86 mm |
| **Double-column width** | 178 mm |
| **Text size** | ≥8 pt after reduction; line width 0.5–1 pt |
| **Upload** | Each figure as an **individual file** |
| **Legends** | In the manuscript text, **after the References section** |

Run `.\build.ps1 -ExportFigures -Chapter N` to produce submission-ready TIFFs.
Output: `output/submission/cpt_psp/chNN/figures/Figure_N.tiff`

**Per-figure DPI assignments (current chapters):**

| Figure | File | Width | DPI | Reason |
|---|---|---|---|---|
| CH_2 Fig 1 | `pgx_architecture_clinical_ooda_loop.png` | 178 mm | 300 | Color halftone |
| CH_2 Fig 2 | `pgx_architecture_pipeline.png` | 178 mm | 300 | Color halftone |
| CH_2 Fig 3 | `pgx_architecture_consensus_filter.png` | 178 mm | 300 | Color halftone |
| CH_2 Fig 4 | `pgx_architecture_risk_dashboard.png` | 178 mm | 300 | Color halftone |
| CH_2 Fig 5 | `fig_attrition.png` | 86 mm | 400 | Contains text (flow diagram) |
| CH_4 Fig 1 | `fig_shap.png` | 86 mm | 300 | Color halftone |
| CH_4 Fig 2 | `fig_network.png` | 178 mm | 300 | Color halftone |
| CH_4 Fig 3 | `fig_ir.png` | 86 mm | 300 | Color halftone |
| CH_4 Fig 4 | `fig_zcode.png` | 178 mm | 300 | Color halftone |

To change a figure's DPI or width, edit `CHAPTER_FIGURES` in
`templates/export_figures_psp.py`.

### Tables

| Attribute | Requirement |
|---|---|
| **Format** | MS Word DOC or DOCX |
| **Numbering** | Consecutive in order of first citation |
| **Multipart tables** | Not allowed (no Table 1a / 1b) |
| **Characters per row** | ≤ 130 |
| **Title** | Brief title on the table; explanatory matter in footnotes |
| **Upload** | Each table as a separate DOCX file |

Tables are embedded in the manuscript DOCX as standard Word tables.
They do **not** need to be exported separately for main manuscript tables.

### Supplementary Information

| Attribute | Requirement |
|---|---|
| **Naming** | Figure S1, Figure S2 … / Table S1, Table S2 … |
| **Captions** | Placed **within** the supplementary file (not in the manuscript) |
| **Formats** | PDF, DOC/DOCX, Excel, TIFF, EPS |
| **Supp image size** | ≤ 640 × 480 pixels |
| **Max files** | 8 (figures and tables may be combined into one PDF) |
| **Max file size** | 10 MB per file |
| **Copyediting** | None — files appear exactly as submitted |

Supplementary TIFFs (≤640×480) are generated by `export_figures_psp.py`
alongside the TIFF submission folder:
`output/submission/cpt_psp/chNN/supp/Figure_SN.tiff`

Supplementary tables (DOCX) are generated by `make_supp_tables.py` (Pass 2d)
and placed in `output/submission/cpt_psp/chNN/supp/Table_SN.docx`.

> **Combining supplementary files:** PSP recommends ≤8 files. If you have
> multiple supplementary figures and tables, combine into one PDF before
> upload. Captions must be included within the combined file.

### Figure Legends in Manuscript

PSP requires figure legends to appear **after the References section** in the
manuscript text, not inline with the figures. The current build places captions
inline (standard Quarto behaviour). Before final submission:

1. Open `output/edits/cpt_psp/chNN_draft.docx` in Word.
2. Cut all figure captions from their inline positions.
3. Paste them as a "Figure Legends" section after the final reference entry.

This is a one-time manual step per submission round.

## Submission Checklist (per journal)

### Main Manuscript
- [ ] Upload `output/edits/<journal>/chNN_draft.docx` as **Manuscript**
- [ ] Verify page 1 = title page (title → authors → affiliations → COI)
- [ ] Verify page 2 starts with Abstract
- [ ] Confirm figure + table count ≤ journal limit (PSP/CTS: 7; CTS Review: 8)

### Supplementary Material (upload as separate files)
- [ ] `Figure_S1.png`, `Figure_S2.png`, … from `output/submission/<journal>/chNN/supp/`
- [ ] `Table_S2.docx`, … from same folder
- [ ] Pipeline-generated tables (e.g., Table S1 — 115 DDI pairs) exported from
  analysis notebook and uploaded separately

### Per-Journal Limits

| Journal | Max figures+tables | Notes |
|---|---|---|
| CTS Article | 7 | Supplementary figures = separate files |
| CTS Review | 8 | Supplementary files ≤ 8 |
| CPT:PSP | 7 | Supplementary figures = separate files |
